## Preferred CLI Tools
Always use these modern high-performance CLI utilities instead of legacy coreutils when running bash commands:

- Use `fd` instead of `find` for file searches (respects .gitignore automatically).
- Use `sd` instead of `sed` for string replacement/regex refactoring.
- Use `jq` for parsing, querying, and processing JSON data streams.
- Use `fzf` for interactive filtering when command-chaining selections.
